# deepstack: working rules for Claude

Public repo. Everything committed here is published at https://siv73.github.io/deepstack.

- Lessons are made with the `deepstack` skill. Read `authoring/` before writing a lesson.
- Lesson source only: `content/<slug>/`, `examples/<slug>/`.
- `site/` is generated by CI and is never committed.
- Tooling (`tools/`, `ui/`, configs) lives in this repo and is changed here, not synced from a skill.
- Before every push: `make check` must pass (in the cloud workspace set `TS_CHROME` to the
  preinstalled Chromium if Playwright's download is blocked).
- Pages run under a strict CSP: no inline scripts, no `style=` attributes, no event-handler
  attributes, no third-party requests. Set styles from JS through CSSOM (`el.style.x`).
- Never commit secrets, `.env` files, personal data, employer or client names, or local paths.
- Commits use the noreply identity `Sivasai Gavara <siv73@users.noreply.github.com>`.
